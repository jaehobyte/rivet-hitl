# 모의 인터뷰 스킬 평가표 — 사람 채점용

각 항목 0(실패), 1(일부), 2(충족), 총 20점. 이 점수는 **연습용 루브릭**이지 공식 채점 기준이 아니다.

| 기준 | 0 / 1 / 2 판단 |
|---|---|
| 1. 사전 조사 | README가 이미 설명한 것을 다시 질문하지 않는가? |
| 2. 커버리지 | FR·BR·핵심 예외·주요 NFR·AC의 중요한 미정을 모두 발견했는가? |
| 3. 구분 | confirmed vs hypothesis vs open을 혼동하지 않는가? |
| 4. 결정 차이 | 각 P0가 답 A/B에서 무엇을 바꾸는지 명확한가? |
| 5. 중립성 | 해결책을 강요하지 않는 문제 중심 질문인가? |
| 6. 질문 단위 | 질문 한 개가 한 핵심 판단을 묻는가? |
| 7. 우선순위 | 안전·업무 불변조건·AC를 모호한 UI보다 먼저 확인하는가? |
| 8. 기록 | 새 Q&A를 해석 이전에 원문 그대로 누적하는가? |
| 9. 적응 | 답변으로 이미 해결된 질문을 제거하고 진짜 후속 P0를 찾는가? |
| 10. 종료 | 핵심 정보가 충분하면 P2를 끝없이 묻지 않고 종료하는가? |

## 실패 모드 4개
- **기술 해법 유도**: "Redis 락 사용하시겠어요?"는 현업 인터뷰 질문 부적절.
- **중복 질문**: 답변에서 이미 '기존 주문 유지'가 나왔는데 다시 묻는 것.
- **증거 조작**: 인터뷰에 없던 정확한 TPS·시간 제한을 confirmed 처리.
- **과도한 탐색**: 180분 안에 구현하지도 않을 사소한 정책을 끝없이 물음.
